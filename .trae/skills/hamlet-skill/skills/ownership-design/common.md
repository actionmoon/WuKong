## 适用场景（什么时候读这个文件）

- 写同步 / 网络变量前判断哪端有写权限
- 主权的请求 / 审批 / 转移 / 断线迁移
- 区分主权（谁能写状态）与控制权（谁在使用对象）
- 多人按钮 / 拾取 / 放下 / 座位 / Pet 合养等写权限链路
- 排查非主权方写入无效、状态被改回、断线后无人接管
