## 适用场景（什么时候读这个文件）

- 消费摇杆 / WASD / 触摸 / 跳跃 / 缩放输入
- 把摇杆、键盘、Runtime UI、官方按钮汇入同一状态
- 进入无人机、机械炮塔、加特林等遥控或被控对象控制状态
- 写长按、抬起、蓄力、连发、持续开火、持续升降
- 排查“UI 按钮生效但 WASD 不生效”“松手后还在移动 / 开火”等问题
- 了解输入采样的能力边界和事件分类
