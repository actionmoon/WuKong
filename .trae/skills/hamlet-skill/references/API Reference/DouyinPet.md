# 描述
DouyinPet 类表示游戏中小火人的相关信息和操作。
提供了小火人的基本属性和操作方法。
# 公开属性
| 属性 | 描述 |
| --- | --- |
| [petID](./DouyinPet/DouyinPet.petID.md) | 获取合养精灵的 ID |
| [petOpenID](./DouyinPet/DouyinPet.petOpenID.md) | 合养精灵的唯一标识符，在创建合养精灵对象时进行初始化，属性为只读。 |
| [petName](./DouyinPet/DouyinPet.petName.md) | 获取合养精灵的名称 |
| [petLevel](./DouyinPet/DouyinPet.petLevel.md) | 获取合养精灵等级 |
| [petAppearance](./DouyinPet/DouyinPet.petAppearance.md) | 获取合养精灵的形象 |
| [petAccesory](./DouyinPet/DouyinPet.petAccesory.md) | 获取合养精灵的装扮列表 |
| [isMaster](./DouyinPet/DouyinPet.isMaster.md) | 判断当前用户是不是控制者 |
# 公开方法
| 方法 | 描述 |
| --- | --- |
| [GetActor](./DouyinPet/DouyinPet.GetActor.md) | 获取该 Douyinpet 关联的 Actor |
| [GetPetPortrait](./DouyinPet/DouyinPet.GetPetPortrait.md) | 获取该DouyinPet的头像 |
