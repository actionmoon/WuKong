# 描述
负责管理 DouyinPet 的实例。
它提供一系列静态方法，用于创建、移除、获取单个或多个 DouyinPet 实例（合养精灵）
# 静态方法
| 方法 | 描述 |
| --- | --- |
| [GetPet](./DouyinPetService/DouyinPetService.GetPet.md) | 通过 PetID，获取当前场景内的合养精灵 |
| [GetLocalPet](./DouyinPetService/DouyinPetService.GetLocalPet.md) | 获取当前玩家控制的合养精灵 |
| [GetPets](./DouyinPetService/DouyinPetService.GetPets.md) | 获取当前场景内所有的合养精灵 |
| [GetPetCount](./DouyinPetService/DouyinPetService.GetPetCount.md) | 获取当前场景内合养精灵的数量 |
