# 描述
 创作者信息类，用来存储创作者信息。
# 公开属性
| orderStatus | DouyinOrderStatus | 交易订单的状态 |
| --- | --- | --- |
| purchaseOrder | string | 交易订单 |
| playerOpenId | string | 交易用户的OpenId |
| petOpenId | string | 交易精灵的OpenId |
| productId | string | 商品id |
| productNum | int | 商品交易数量 |
| productPrice | Int64 | 商品交易价格 |
| orderPrice | Int64 | 订单的总价 |
| orderData | string | 订单的额外信息 |
| purchaseTime | Int64 | 发货时间 |
