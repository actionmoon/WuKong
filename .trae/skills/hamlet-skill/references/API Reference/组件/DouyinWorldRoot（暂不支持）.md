# 描述
您可以通过这个类来设置重生逻辑和Actor的运动属性
# 公开属性
| 属性 | 描述 |
| --- | --- |
| [Spawns](./DouyinWorldRoot/DouyinWorldRoot.Spawns.md) | 玩家的出生点数组 |
| [SpawnOrder](./DouyinWorldRoot/DouyinWorldRoot.SpawnOrder.md) | 出生点的顺序规则 |
| [RespawnHeightY](./DouyinWorldRoot/DouyinWorldRoot.RespawnHeightY.md) | 玩家的重生高度 或 拾取物品的重生/销毁高度 |
| [PlayerRespawnLogic](./DouyinWorldRoot/DouyinWorldRoot.PlayerRespawnLogic.md) | 玩家重生逻辑 |
| [ObjectBehaviourAtRespawn](./DouyinWorldRoot/DouyinWorldRoot.ObjectBehaviourAtRespawn.md) | 物体重生逻辑 |
| [GuestSpawn](./DouyinWorldRoot/DouyinWorldRoot.GuestSpawn.md) | 游客出生点 |
| [MaxSpeed](./DouyinWorldRoot/DouyinWorldRoot.MaxSpeed.md) | 玩家最大移动速度 |
| [JumpHeight](./DouyinWorldRoot/DouyinWorldRoot.JumpHeight.md) | 玩家的跳跃高度 |
| [CustomCameraList](./DouyinWorldRoot/DouyinWorldRoot.CustomCameraList.md) | 自定义相机列表，该列表中的相机被加载进世界时不会被删除 |
| [NetSpawnObjectAsset](./DouyinWorldRoot/DouyinWorldRoot.NetSpawnObjectAseet.md) | 从网络生成对象 |
