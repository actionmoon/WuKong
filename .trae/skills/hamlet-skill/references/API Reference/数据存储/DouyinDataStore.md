# 描述
DouyinDataStore 类是抖音数据存储相关的核心类，提供了一系列用于数据存储、检索、更新和删除的方法。
# 公开方法
| 方法 | 描述 |
| --- | --- |
| [GetData](./DouyinDataStore/DouyinDataStore.GetData.md) | 根据键获取数据 |
| [SetData](./DouyinDataStore/DouyinDataStore.SetData.md) | 设置数据 |
| [IncrementData](./DouyinDataStore/DouyinDataStore.IncrementData.md) | 对数值型数据进行增量操作 |
| [RemoveData](./DouyinDataStore/DouyinDataStore.RemoveData.md) | 删除与键对应的数据 |
| [UpdateData](./DouyinDataStore/DouyinDataStore.UpdateData.md) | 通过回调函数更新与键对应的数据 |
