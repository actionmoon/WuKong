# 描述
此对象提供了关于单个数据对象的详细信息。
# 公开属性
| 属性 | 类型 | 描述 |
| --- | --- | --- |
| version | number | 当前数据版本号 |
| key | string | 键 |
| value | number，string, boolean, 或包含这些类型的表 | 值 |
| createdTime | number | 创建时间 |
| updateedTime | number | 最后更新时间 |

| 方法 | 描述 |
| --- | --- |
| [GetMetaData](./DouyinDataInfo/DouyinDataInfo.GetMetaData.md) | 获取数据对象的元信息 |
