# 描述
您可以使用这个类来设置传入的元数据表。
# 公开方法
| 方法 | 描述 |
| --- | --- |
| [GetMetaData](./DouyinDataSetOptions/DouyinDataSetOptions.GetMetaData.md) | 获取自定义元数据的值，即Datasetoptions对象的值 |
| [SetMetadata](./DouyinDataSetOptions/DouyinDataSetOptions.SetMetadata.md) | 设置自定义元数据的值，即Datasetoptions对象的值 |
| [SetPlayerDataOwner](./DouyinDataSetOptions/DouyinDataSetOptions.SetPlayerDataOwner.md) | 设置数据关联的玩家（仅用于检测），平台侧即可检测到该玩家因多房间同时写入而导致的数据回档异常。 |
| [SetPetDataOwner](./DouyinDataSetOptions/DouyinDataSetOptions.SetPetDataOwner.md) | 设置数据关联的火人（仅用于检测），平台侧即可检测到该火人因多房间同时写入而导致的数据回档异常。 |
