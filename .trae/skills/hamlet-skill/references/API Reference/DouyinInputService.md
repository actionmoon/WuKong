# 描述
主要负责管理和处理与用户输入相关的各类事件，涵盖了屏幕点击、移动输入、视角旋转、屏幕缩放以及跳跃等操作的事件监听与响应。
# 静态事件
| 事件 | 描述 |
| --- | --- |
| [onTouchEvent](./DouyinInputService/DouyinInputService.onTouchEvent.md) | 屏幕点击事件 |
| [onMoveInputStart](./DouyinInputService/DouyinInputService.onMoveInputStart.md) | 开始有移动输入 |
| [onMoveInputPerform](./DouyinInputService/DouyinInputService.onMoveInputPerform.md) | 持续有移动输入 |
| [onMoveInputCancel](./DouyinInputService/DouyinInputService.onMoveInputCancel.md) | 移动输入取消 |
| [onLookInputStart](./DouyinInputService/DouyinInputService.onLookInputStart.md) | 旋转视角操作开始 |
| [onLookInputPerform](./DouyinInputService/DouyinInputService.onLookInputPerform.md) | 旋转视角（屏幕空白区域） |
| [onLookInputCancel](./DouyinInputService/DouyinInputService.onLookInputCancel.md) | 旋转视角操作取消 |
| [onZoomInput](./DouyinInputService/DouyinInputService.onZoomInput.md) | 屏幕缩放（双指） |
| [onJumpInputStart](./DouyinInputService/DouyinInputService.onJumpInputStart.md) | 跳跃，无论在 PC 上按下空格，还是手机屏幕点击跳跃，均触发跳跃输入事件 |
| [onJumpInputPerform](./DouyinInputService/DouyiuInputService.onJumpInputPerform.md) | 跳跃时事件 |
| [onJumpInputCancel](./DouyinInputService/DouyinInputService.onJumpInputCancel.md) | 取消跳跃事件 |
