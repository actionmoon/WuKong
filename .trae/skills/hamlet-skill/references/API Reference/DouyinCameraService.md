# 描述
用于管理与相机相关的功能，包括相机模式的切换、相机参数的获取和设置等。
# 静态事件
| 事件 | 描述 |
| --- | --- |
| [onCameraModeChanged](./DouyinCameraService/DouyinCameraService.onCameraModeChanged.md) | 相机模式切换 |
# 静态方法
| 方法 | 描述 |
| --- | --- |
| [GetCamera](./DouyinCameraService/DouyinCameraService.GetCamera.md) | 获取与主角绑定的相机 |
| [GetPitch](./DouyinCameraService/DouyinCameraService.GetPitch.md) | 获取主相机与主角之间的俯仰角，游戏模式有效 |
| [SetPitch](./DouyinCameraService/DouyinCameraService.SetPitch.md) | 设置主相机与主角之间的俯仰角，游戏模式有效 |
| [GetYaw](./DouyinCameraService/DouyinCameraService.GetYaw.md) | 获取主相机与主角之间的偏航角，游戏模式有效 |
| [SetYaw](./DouyinCameraService/DouyinCameraService.SetYaw.md) | 设置主相机与主角之间的偏航角，游戏模式有效 |
| [SetDistance](./DouyinCameraService/DouyinCameraService.SetDistance.md) | 设置主相机与主角之间的距离，游戏模式有效 |
| [SetOffset](./DouyinCameraService/DouyinCameraService.SetOffset.md) | 设置主相机主角（目标点）位置偏移，游戏模式有效 |
| [IsPhotographMode](./DouyinCameraService/DouyinCameraService.IsPhotographMode.md) | 判断当前相机功能模式的状态 |
| [StartPhotograph](./DouyinCameraService/DouyinCameraService.StartPhotograph.md) | 进入相机功能模式 |
| [StopPhotograph](./DouyinCameraService/DouyinCameraService.StopPhotograph.md) | 停止相机功能模式 |
