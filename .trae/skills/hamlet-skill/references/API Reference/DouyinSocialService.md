# 描述
平台向API，封装了一些平台向的事件和方法。
# 静态事件
| 事件 | 描述 |
| --- | --- |
| [onPublishProcessEvent](./DouyinSocialService/DouyinSocialService.onPublishProcessEvent.md) | 监听玩家的抖音视频的投稿发布状态 |
| [onPublishResultEvent](./DouyinSocialService/DouyinSocialService.onPublishResultEvent.md) | 用于监听玩家的抖音视频的投稿结果 |
| ShareWorld | 该函数用于将当前的游戏世界分享给他人 |
| ShareTexture | 该函数用于将指定的图片分享给他人 |
