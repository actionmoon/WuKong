| [GetPlayers](./DouyinPlayerService/DouyinPlayerService.GetPlayers.md) | 获取当前房间内所有的 DouyinPlayer |
| [GetPlayerCount](./DouyinPlayerService/DouyinPlayerService.GetPlayerCount.md) | 获取当前房间 DouyinPlayer 的数量 |
| [GetPlayerByOpenID](./DouyinPlayerService/DouyinPlayerService.GetPlayerByOpenID.md) | 通过open ID获取房间内的DouyinPlayer |
