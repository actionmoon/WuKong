# 基础交互组件

> **适用范围**：当 [hamlet-preferences.md](../../../hamlet-preferences.md) 中 `DevTool=UnityEditor` 时阅读。
> `DevTool` 的详细说明请参考[开发工具概述](../../Manual/VI.%20开发工具/开发工具概述.md)。

为了降低开发门槛，抖音虚拟世界 SDK 提供了内置的交互和拾取组件。无需编写复杂的射线检测或距离计算代码，直接挂载组件即可实现标准的玩家互动行为。

## 1. 交互组件（DouyinInteractor）

`DouyinInteractor` 用于实现玩家与世界静态或动态物体互动的效果（例如：走近开关出现按钮，点击后开门）。

### 配置步骤
1. 在目标 GameObject 上添加 **Douyin Script** 组件。
2. 将 SDK 提供的 `DouyinInteractor` 脚本拖入脚本文件中。
3. 在组件面板上配置交互逻辑：

### 核心属性
* **交互触发范围**：
  * **圆形区域**：在物体中心生成隐形的球形触发器（指定范围半径）。
  * **自定义范围**：可手动拖入自定义的 Collider 以构建不规则触发区域。
* **交互按钮设置**：
  当玩家进入触发范围时，UI 层会弹出的交互按钮。可自定义按钮图标、底板背景、显示文本及文本颜色。
* **交互逻辑**：
  * **脚本**：关联挂载了自定义 `Douyin Script` 的目标物体。
  * **方法**：输入目标脚本中的 Lua 方法名称。当玩家点击弹出的交互按钮时，会自动触发调用该方法。

## 2. 拾取组件（DouyinPickUp）

`DouyinPickUp` 允许玩家拿起、持有、丢弃世界中的物体。当玩家靠近物体时，物体边框会高亮，并出现拾取按钮。拾取后可进一步配置副交互功能（例如：拿起汉堡后，点击副按钮触发“吃”的动作）。

*(预制体路径：`Assets/DouyinVCreateSDK/World/Examples/DouyinPickup`)*

### 配置步骤
1. 为物体添加 **Douyin Script** 组件并配置 `DouyinPickUp` 脚本。
2. 挂载后，系统会自动添加同步组件 **Douyin Object Sync**（拾取物必须是网络对象）。

### 核心属性
* **拾取物基础属性设置**：
  * **物品持握位置**：默认右手拾取。若是合养精灵，持握位置为右手挂点。
  * **丢弃逻辑**：配置“可被丢弃”、“丢弃后是否销毁”、“丢弃后自动销毁时间”（注意：只有通过 `NetSpawn` 动态生成的网络对象才能被真正销毁，静态放置的物品无法被销毁）。
  * **主权转移**：配置“拾取后可被他人拿走”。拾取本质上是主权（Ownership）的转移。
* **主功能/副功能按钮设置**：
  支持自定义图标、文本及触发逻辑，按钮类型可选“普通按钮”或“摇杆”。拾取后，主副按钮会覆盖或叠加显示在主界面。
* **交互逻辑绑定**：
  类似基础交互组件，绑定目标脚本与方法名，点击按钮即触发对应的 Lua 方法执行自定义业务。

## 3. 座位组件（DouyinSeat）

`DouyinSeat` 用于实现玩家坐下和站起的标准座位交互。玩家靠近座位时会出现交互入口，点击“坐下”后移动到座位指定位置；坐下后可通过“站起”入口离开座位。

预制体路径：`Assets/DouyinVCreateSDK/World/Examples/DouyinSeat`

### 配置步骤
1. 在座椅模型上添加 **Douyin Script** 组件。
2. 在脚本文件中添加 SDK 提供的 `DouyinSeat` 脚本。
3. 配置交互触发范围、坐下位置、站起位置和按钮表现。

### 核心属性
* **交互触发范围**：
  * **圆形区域**：在物体中心生成球形触发器，通过范围半径控制交互距离。
  * **自定义范围**：拖入自定义 Collider，通过调整 Collider 大小控制交互范围。
* **座位设置**：
  * **坐下位置**：玩家坐下后所在的位置，通过座位上的坐下挂点配置。
  * **站起位置**：玩家站起后所在的位置，通过座位旁的站起挂点配置。
  * **自定义坐下动作**：配置玩家坐下时播放的动画。
* **坐下按钮设置**：
  * **按钮图标**：配置坐下入口的图标；官方组件默认提供对应图标。
  * **按钮底板**：配置按钮底板图片。
  * **按钮文本**：默认为“坐下”。
  * **文本颜色**：配置按钮文本颜色，默认使用黑色。
