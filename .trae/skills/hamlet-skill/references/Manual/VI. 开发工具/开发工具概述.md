# 开发工具概述

Hamlet 文档描述抖音虚拟世界的运行时 API。使用资料前，必须读取 [hamlet-preferences.md](../../../hamlet-preferences.md) 中的 `DevTool`，确认运行时 API 所处的开发工具。

`DevTool` 只接受以下值：

- `UnityEditor`：在 Unity Editor 中使用抖音虚拟世界SDK 开发。
- `AIEditor`：在 AI 编辑器中开发，并在 Hamlet API 规范之上遵守 `lua-script-contract`。

`DevTool` 缺失或值无效时，先要求用户明确开发工具。不得根据 `Language`、文件路径、代码示例或当前目录推断。

## 资料选择

- `DevTool=UnityEditor`：读取 [Unity Editor开发](./Unity%20Editor开发.md)，再按任务选择 Hamlet 的 Manual、Best Practice、编码规范和 API Reference。
- `DevTool=AIEditor`：加载 [AI Editor开发](./AI Editor开发.md)。Hamlet 文档只用于查询运行时 API 的语义、签名和平台限制；Unity Editor 的工程目录、Hierarchy、Inspector、Prefab、组件挂载和模拟器操作不适用。

无论使用哪种工具，调用抖音虚拟世界SDK API 前都必须通过 [API Reference Index](../../API%20Reference%20Index.md) 定位具体页面，并核对 [API 白名单](../../API白名单.md)和 [API 黑名单](../../API黑名单.md)。


## 差异速查

| 场景 | UnityEditor | AIEditor |
| --- | --- | --- |
| 可交付脚本 | Lua、C#，由 Unity 工程配置决定 | 当前归档链路只接受规定目录与命名的 Lua |
| 脚本组织 | DouyinScript、Loader、ModuleScript、工程目录 | 独立 DouyinScript 脚本树；不创建自定义 Loader 或 `index.lua` |
| 参数配置 | Unity Inspector 或 抖音虚拟世界SDK 工程配置 | `---@var` 参数声明与 AIEditor 参数面板 |
| 组件配置 | Hierarchy、Inspector、Prefab | `meta.json`、`anchor.json`、attributes 和受控生成工具 |
| 自定义 UI | Unity UGUI、Canvas、Prefab | Runtime UI 的 HTML、图片、Lua 与归档流程 |
| 跨对象脚本访问 | 按 抖音虚拟世界SDK 工程架构实现 | Runtime Host 与 RuntimeScope |
| C# / DS 工程 | 工程满足前提时可使用 | 暂不支持 |
| 场景与网络配置 | 工程满足前提时可使用 | 暂不支持 |
| 验证方式 | Unity 编译、模拟器与目标环境 | Lua 检查、资源归档及 Creator 预览；未运行的能力必须标明未验证 |
