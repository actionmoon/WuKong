# 角色移动、飞行与游泳

`DouyinActor` 提供玩家角色的地面移动、跳跃、传送、速度调整、飞行和游泳状态能力。本页说明 API 和状态语义。**使用这些 API 开发前，应优先阅读[角色控制开发约束](../../../Ⅲ.%20逻辑与脚本%28Logic%26Scripting%29/编码约束与开发规范/角色控制开发约束.md)，其中包含通用开发规范、专项避坑和常见问题。**

## 一、角色控制范围

角色控制 API 面向玩家自身。远端玩家的位置、移动和飞行表现由网络同步驱动。

- 玩家自身：使用 `DouyinActor` 的移动、飞行和游泳 API。
- 可驾驶载具和飞行载具：使用载具脚本与 `Rigidbody` 或专用运动逻辑。
- 场景物体：使用 `Rigidbody`、动画或业务脚本。

## 二、基础地面移动

| API | 用途 |
| --- | --- |
| `actor.speed` | 读写玩家行走速度上限。 |
| `actor:SetSpeed(speed, baseRate)` | 设置速度，并可同步调整动画播放倍率。 |
| `actor:MoveContinuously(Vector2 direction)` | 让玩家持续朝指定方向移动，适用于剧情引导或受迫移动。 |
| `actor:StopMove()` | 停止持续移动。 |
| `actor:Immobilize(bool immobile)` | 禁止或恢复摇杆输入，不影响重力和碰撞。 |
| `actor:Jump()` | 触发一次跳跃。 |
| `actor:Teleport(pos, rot)` | 传送到指定位置，可同时指定朝向。 |

`MoveContinuously` 用于模拟持续方向输入；`Immobilize` 用于锁定玩家自己的摇杆输入。加速带、冰面、泥潭、疾跑和缓行等效果通常通过缩放 `actor.speed` 实现，不是真实 `Rigidbody` 摩擦。

## 三、飞行与悬浮

飞行能力同时受业务调用、房间设置和角色配置影响。

| 类型 | API | 用途 |
| --- | --- | --- |
| 权限与按钮 | `actor:EnableFly()` / `actor:DisableFly(hideUI)` | 控制飞行权限和按钮显示。 |
| 飞行状态 | `actor:StartFly(initHeight)` / `actor:StopFly()` | 进入或退出飞行状态。 |
| 飞行模式 | `actor:SetFlyMode(mode)` | `1` 为自由飞行，`0` 为原地上下的悬浮。 |

`actor:CanFly()` 用于查询当前角色是否具备飞行能力。`DisableFly` 只处理飞行权限和按钮，不会自动结束当前飞行；`StopFly` 也不会自动禁用飞行按钮。

## 四、游泳

游泳是水体触发的被动状态。玩家接触 SDK 定义的水体后自动进入或退出游泳，业务侧不能主动开启游泳。

| API / 事件 | 用途 |
| --- | --- |
| `actor:CanSwim()` | 查询角色是否具备游泳能力。 |
| `actor:IsSwimming()` | 查询当前是否处于游泳状态。 |
| `actor.onSwimStart` / `actor.onSwimStop` | 监听游泳状态变化。 |

`CanSwim()` 受房间设置和角色配置限制；返回 `false` 时，角色接触水体也不会进入游泳状态。游泳期间是否允许拾取、使用技能或飞行，属于具体玩法的业务规则。
