# 玩家网络对象概述

玩家对象是抖音虚拟世界中代表和管理玩家的核心对象体系。每个进入房间的玩家都会在网络层生成相应的映射，构成了严密的层级关系：

## 核心对象层级

### 1. DouyinPlayer（玩家实体）
`DouyinPlayer` 代表一个加入房间的真实用户，是最顶层的玩家标识层。
* **核心属性**：拥有唯一的 `playerID`、`playerOpenID`、`playerName` 等属性。
* **生命周期感知**：玩家进房时触发全局事件 `OnPlayerJoined`，退出时触发 `OnPlayerLeft`。
* **数据获取**：可通过 `DouyinPlayerService` 获取当前房间内的所有玩家列表或指定玩家。

### 2. DouyinActor（玩家控制的网络对象）
每个玩家进房后，系统会生成对应的 `DouyinActor`，代表玩家在世界中的具体角色映射。
* **功能**：负责角色在 3D 世界中的实际控制，其位置、动画状态机、语音等表现信息会自动在多端同步。
* **控制对象细分**：根据业务类型的不同，`DouyinActor` 可能会关联不同的具体控制对象：
  * **DouyinAvatar**：玩家的虚拟形象表现层，负责角色的 3D 外观渲染和动作动画。
  * **DouyinPet**：玩家关联的合养精灵对象（宠物）。
  
> **⚠️ 仔仔世界场景限制**：在部分特殊场景（如仔仔世界）下，`DouyinPet` 及其服务 `DouyinPetService` 整个类禁止使用。此时访问 `DouyinActor.isPet` 或 `DouyinActor.douyinPet` 会返回 null/false 并抛出警告。此外，在玩家退出触发 `OnActorDespawned` 时，访问 `douyinPet` 同样会得到 `nil`。

---

## 玩家生命周期关联的网络对象

除了代表玩家本身的 `DouyinActor` 外，玩家在运行过程中还可以动态创建依附于自身的附属网络对象：
* **创建方式**：通过调用 `DouyinActor.NetSpawn` 创建。
* **生命周期绑定**：此类对象与创建它的 `DouyinActor` 的生命周期强绑定。
* **自动销毁**：当该玩家退出房间（`DouyinActor` 被销毁）时，这些关联的网络对象会自动销毁，无需开发者手动管理。当然，也可以在生命周期内存续期间手动调用 `DouyinActor.NetDestroy` 进行提前销毁。
* **适用场景**：适用于与角色表现强关联的附属功能，如角色头顶的血条 UI、跟随在身边的专属粒子特效、特定的持握道具等。
