# 游戏对象的概述

抖音虚拟世界（Douyin World）是一个多人在线互动平台，游戏对象是构成世界的基本单位。按照是否参与网络同步，游戏对象分为**非网络对象**和**网络对象**两大类。

## 非网络对象
使用 `GameObject.Instantiate` 创建的对象为非网络对象。非网络对象不支持同步变量和 RPC 消息，其变化仅在本地可见，其他玩家无法感知。适用于不需要多端同步的纯本地逻辑表现（如本地粒子特效、本地 UI 元素等）。

## 网络对象
网络对象是指需要在所有客户端之间同步状态的对象。默认情况下，世界中的对象是局部的，要使其支持网络同步，需要为其添加 `Douyin Object Sync` 或 `Douyin Script` 组件。世界中自带网络同步功能的组件（如 Douyin Portal、Douyin MusicPlayer、DouyinVideoPlayer）以及玩家角色本身也是网络对象。

### 网络对象的分类

| **分类维度** | **对象细分** | **描述说明** |
| --- | --- | --- |
| **创建时机** | **静态网络对象** | 默认在 Unity 场景中预置放置的网络对象，随场景加载自动创建。<br>• **一致性**：所有客户端加载的静态对象完全相同。<br>• **初始主权**：通常归属于房间创建者（SharedMode）或服务器（DS模式）。<br>• **网络就绪状态**：当其触发 `OnNetSpawned` 时，房间数据仍在同步中，此时 `isNetworkSettled` 为 **false**。<br>• **销毁**：随场景卸载而销毁。 |
| | **动态网络对象** | 运行时通过代码动态创建（`NetSpawn`）的对象。<br>• **一致性**：依赖创建时机，后加入的玩家会收到状态快照。<br>• **初始主权**：归属于调用 `NetSpawn` 的一方（SharedMode）或 DS 服务端。<br>• **网络就绪状态**：由于通常在进房后创建，其触发 `OnNetSpawned` 时 `isNetworkSettled` 通常为 **true**。<br>• **销毁**：必须主动调用对应的 `NetDestroy` 方法（玩家绑定对象会自动随玩家销毁）。 |
| **生命周期** | **房间网络对象** | 与房间的生命周期一致，房间创建时创建，销毁时销毁：<br>1. 所有**静态网络对象**均属于此类。<br>2. `DouyinObjectService.NetSpawn` 创建的动态对象。创建者下线后该对象依然留存在房间中。**必须主动调用 `DouyinObjectService.NetDestroy` 销毁，否则容易导致对象堆积。** |
| | **玩家关联对象** | 与特定玩家的生命周期绑定：<br>通过 `DouyinActor.NetSpawn` 创建的动态对象。当创建它的玩家（`DouyinActor`）离开房间或被销毁时，该对象也会自动随之销毁（也可手动调用 `DouyinActor.NetDestroy` 提前销毁）。 |
| **对象类别** | **玩家网络对象** | 代表玩家控制的角色实例：`DouyinActor`。 |
| | **普通网络对象** | 除玩家对象外的所有对象，统称为 `DouyinObject`（包含所有静态对象和动态创建的物品）。 |

### 动态生成网络对象

在运行时动态生成网络对象，需要进行前置配置：
1. 创建 **Douyin Net Spawn Object Asset** 并将其关联到 `Douyin World Root` 组件的“网络对象生成配置”列表中，设置唯一的主键（Key）。
2. 在代码中调用对应的 API 进行生成。
   - **房间级对象**：使用 `DouyinObjectService.NetSpawn`，不会随玩家离场而销毁，需要自行管理生命周期。如果是 DS 模式，**必须在服务端创建并显式拦截主权请求**。
   - **玩家绑定对象**：使用 `DouyinActor.NetSpawn`，适合玩家血条、头顶称号等，随玩家自动销毁。
   - **DS 内部对象**：使用 `DouyinObjectService.ServerSpawn` 创建仅服务器可见的对象。

> ⚠️ **关于动态生成的完整 API 用法、主权管理、DS 模式拦截机制以及常见坑点，请参阅：[网络对象的动态创建](../../Ⅳ.%20多人游戏与网络%28Multiplayer%29/网络基础/网络对象的动态创建.md)。**

### 网络对象数量限制说明

为了保证世界运行的性能，各类网络对象均有严格的数量上限：

* **全局总量限制**：所有的网络对象总数 **≤ 8000**
* **静态网络对象**：建议 **≤ 4000**
* **房间动态对象**：通过 `DouyinObjectService.NetSpawn` 创建的对象上限为 **1000**（每多一个玩家允许额外生成 1000 个，但受总上限控制）
* **玩家关联对象**：单玩家通过 `DouyinActor.NetSpawn` 创建的对象上限为 **100**
* **玩家数量**：房间最大人数上限为 **30**

> **提示**：只要挂载了 `DouyinNetworkGuid` 的对象即被视为网络对象，如果某对象仅用于本地表现，请移除该组件以节省网络资源配额。DS 模式下，`DouyinServerRoot` 及其子节点**严禁挂载 `NetworkObject`**。
