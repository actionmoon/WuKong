# 自定义界面

> **适用范围**：当 [hamlet-preferences.md](../../../hamlet-preferences.md) 中 `DevTool=UnityEditor` 时阅读。
> `DevTool` 的详细说明请参考[开发工具概述](../VI.%20开发工具/开发工具概述.md)。

在虚拟世界中，开发者可以使用 Unity 的 UGUI 系统搭建界面，同时必须处理横竖屏状态的动态切换适配。

## 场景与适用范围

- **UI 模式选择**：决定界面是贴在屏幕上还是跟随 3D 场景物体。
- **UI 显示逻辑**：通过纯配置或 Lua 脚本控制面板的显示与隐藏。
- **多端与横竖屏适配**：在横竖屏切换开启时，确保 UI 布局不会错乱。

## Canvas 模式规范

创建自定义 UI 必须选择正确的 Canvas 渲染模式：

- **Screen Space - Overlay 模式**
  - **适用场景**：绝大多数常规屏幕 UI（如按钮、面板、输入框等）。
  - **约束**：正常显示在屏幕最上层，必须配置好 Sort Order 避免与系统界面冲突。
- **World Space 模式**
  - **适用场景**：3D 场景内的 UI（如悬浮在模型上方、场景内的广告牌等）。
  - **约束**：与场景 3D 物体存在深度关系，受摄像机视角影响。
- **避坑**：当前**不支持** `Screen Space - Camera` 模式，禁止使用。

## UI 显示与隐藏控制

开发者可通过两种方式管理自定义界面的开关状态：

### 1. 无代码方式 (Button 原生事件)
适用于纯展示型面板的简单开关：
- 在按钮 Inspector 面板的 `Button` 组件中添加 `On Click()` 事件。
- 拖入目标 UI 面板（如容器空物体）到 Object 槽位。
- Function 选择 `GameObject -> SetActive(bool)`。
- **打开面板**：勾选 Checkbox（`true`）。
- **关闭面板**：取消勾选 Checkbox（`false`）。

### 2. Lua 脚本控制
适用于带有业务逻辑的复杂界面：
- 创建 Lua 脚本并绑定变量（如 `UIPanel:SetActive(false)`）。
- 在 UI 容器上挂载 `Douyin Script`，绑定 Lua 脚本并拖拽引用。
- 按钮 `On Click()` 事件中拖入挂载了 `Douyin Script` 的对象，选择 `Douyin Script -> CallMethod(string)`，并填入控制方法名（如 `ClosePanel`）。

## 横竖屏切换适配方案

当世界配置开启了横竖屏切换功能时，必须针对横竖屏状态配置布局。SDK 提供了两种适配模式：

### 模式一：单套 UI 适配 (推荐)
使用同一个 UI Prefab，通过记录不同状态的坐标实现自动适配。适用于横竖屏差异不大的界面。
- **准备工作**：在 Canvas 下创建空物体作为容器，搭建 UI 内容后保存为 Prefab。
- **挂载组件**：打开 Prefab，在容器空物体上挂载 `Douyin UIHVAdapterinOnePrefab`。
- **录制布局**：
  - 将 Unity Game 视图切换至横屏（如 2532×1170），在 Prefab 中调整好横屏布局。
  - 切换至竖屏（如 1170×2532），调整竖屏布局。
  - 组件会自动记录这两种状态的数据。
- **生效配置**：在场景父级 Canvas 节点下的该空物体上添加 `Douyin Canvas Adapter` 组件。

### 模式二：双套 UI 适配
准备两套独立的 UI Prefab，横屏和竖屏下完全使用不同的设计。适用于横竖屏布局差异极大的复杂界面。
- **准备工作**：在 Canvas 下创建空物体容器并保存为 Prefab。分别制作“横屏版 Prefab”和“竖屏版 Prefab”，并拖入容器中作为子节点。
- **挂载组件**：在容器 Prefab 上添加 `Douyin UIHVAdapterinTwoPrefab` 组件。
- **指定引用**：在组件槽位中分别拖入对应的横屏子对象和竖屏子对象。
- **生效配置**：同样在场景中的父级 Canvas 下的该容器上添加 `Douyin Canvas Adapter` 组件。
