# 操作按钮

右下角区域是核心操作动作与自定义操作区。系统通过 `UIType.CustomMain` 和 `UIType.CustomSub` 在该区域提供主、副两个自定义操作入口。它们适用于驾驶、飞行、战斗、蓄力等**持续玩法上下文**。

## 场景与适用范围

右下角操作按钮适合在玩家已进入某个玩法上下文后，作为持续存在的主、副操作键使用：
- **载具驾驶**：加速、刹车、喇叭。
- **飞行控制**：上升、下降、加速。
- **战斗操作**：开火、瞄准、蓄力。
- **骑乘与特殊技能**：冲刺、持续施法、长按确认。

> **提示**：关于与基础交互按钮的边界对比，请参阅 [交互按钮分类与使用规范](./交互按钮分类与使用规范.md)。

## 输入语义与消费规范

右下角按钮可以承载单击、持续按住和长按三类操作。实现时应先确定按钮的业务语义：

- **单击 (按下 → 松开)**：在单击事件中触发一次业务入口。
- **持续操作 (按下 → 持续 → 松开)**：按下时置为按住，松开时清零。必须在 `FixedUpdate()` 中持续消费状态。
- **长按 (按下 → 持续计时 → 达到阈值 / 松开)**：在持续更新阶段累计时间，区分短按、长按开始、长按持续和长按结束。

> **避坑**：持续操作不能只处理单击事件。按钮按下和松开必须成对处理；离开玩法、按钮被替换或对象销毁时，也必须视为一次松开并强制清零状态。

## 标准生命周期与事件绑定

`UIType.CustomMain` 和 `UIType.CustomSub` 是**全局共享槽位**。不要在脚本 `Start()` 中无条件抢占和显示按钮。

### 1. 进入玩法 (如 OnSeatEntered)
- 确认 actor 是本地玩家，并取得玩法控制权。
- 获取 `UIType.CustomMain` / `UIType.CustomSub` 对应的现有按钮。
- **必须先清空按钮上的旧 EventTrigger 条目**，防止上一玩法的回调残留。
- 设置按钮文案和可用状态，绑定 `PointerDown` (held = true) 与 `PointerUp` (held = false)。

### 2. 玩法更新 (FixedUpdate)
- 读取 `held` 等按钮输入状态。
- 合并为最终业务输入，执行移动、物理、开火或蓄力。
- **避坑**：UI 回调只负责更新输入状态，不直接改写刚体速度、位置或旋转。

### 3. 退出玩法 (如 OnSeatExited 或销毁)
- 清空 `EventTrigger` 条目。
- 隐藏 `UIType.CustomMain` / `UIType.CustomSub` 按钮。
- 将按钮引用置空，并将 `held`、长按计时器等临时输入状态全部归零。

## Lua 事件绑定参考

通过 Unity 的 `UnityEngine.EventSystems.EventTrigger` 接收指针事件，最小绑定结构如下：

```lua
local EventTrigger = CS.UnityEngine.EventSystems.EventTrigger
local EventTriggerType = CS.UnityEngine.EventSystems.EventTriggerType

local function BindButton(btn, onDown, onUp)
  if btn == nil or btn.gameObject == nil then return nil end

  local trigger = btn.gameObject:GetComponent(typeof(EventTrigger))
  if trigger == nil then
    trigger = btn.gameObject:AddComponent(typeof(EventTrigger))
  end
  -- 避坑：重新接管槽位前必须清空，否则上一个玩法的回调仍可能被触发
  trigger.triggers:Clear()

  local down = EventTrigger.Entry()
  down.eventID = EventTriggerType.PointerDown
  down.callback:AddListener(function(_) onDown() end)
  trigger.triggers:Add(down)

  local up = EventTrigger.Entry()
  up.eventID = EventTriggerType.PointerUp
  up.callback:AddListener(function(_) onUp() end)
  trigger.triggers:Add(up)

  return trigger
end
```
