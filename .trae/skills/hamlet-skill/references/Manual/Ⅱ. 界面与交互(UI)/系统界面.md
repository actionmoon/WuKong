# 系统界面

系统界面是由官方开发并应用于全量世界的原生 UI。为了在沉浸式或特殊玩法中保持界面纯净，开发者可以通过 API 动态隐藏或禁用部分官方 UI。

## 场景与适用范围

- **布局参考**：开发三方 UI 时，避免与官方系统功能区重叠。
- **全屏沉浸玩法**：隐藏所有的系统功能入口和社交区域。
- **限制玩家能力**：在特定玩法期间禁用飞行、牵手、合养精灵等功能。

## 系统主界面分区规划 (HUD 9宫格)

为了规范化界面布局并避免与官方功能冲突，系统将 HUD 划分为 9 个标准区域。开发者在设计自定义 UI 时，需严格遵循以下空间分配与约束：

- **左上区域 (创作者预留区)**
  - **可用属性**：✅ **创作者可用**
  - **核心功能**：除系统返回按钮外，其余空间预留给创作者使用，适合展示活动面板等。
  - **规范约束**：三方按钮最多 0-5 个（超出会折叠）；图标最大 40*40；标题最多 4 字符 (10pt)；视觉风格需统一。

- **顶部中间区域 (全局快捷功能)**
  - **可用属性**：❌ **不可用 (系统保留)**
  - **核心功能**：系统功能区，包含“在玩朋友”等全局快捷功能。
  - **UI层级**：Native层

- **右上区域 (系统拓展功能)**
  - **可用属性**：❌ **不可用 (系统保留)**
  - **核心功能**：系统功能区，包含“更多世界”、“拍照”、“背包”、“表情”等入口。
  - **UI层级**：Native层

- **左侧中间区域 (跨世界玩法区)**
  - **可用属性**：❌ **不可用 (系统保留)**
  - **核心功能**：官方跨世界玩法区域。
  - **UI层级**：Unity层

- **屏幕中央 (显示区域)**
  - **可用属性**：⚠️ **极不建议占用**
  - **核心功能**：显示玩家角色、名称及气泡信息。
  - **避坑**：**极不建议在此区域长期遮挡 UI**，以免破坏沉浸感和玩家基础体验。

- **右侧中间区域 (基础交互区)**
  - **可用属性**：🟡 **场景动态交互可用**
  - **核心功能**：场景内动态交互按钮区域。
  - **业务场景**：用于承载“交互物交互”、“拾取物拾取”、“座位的坐下”等交互功能。（详见 [基础交互按钮](./系统交互按钮/基础交互按钮.md)）。
  - **UI层级**：Unity层

- **左下区域 (移动控制区)**
  - **可用属性**：❌ **不可用 (系统保留)**
  - **核心功能**：移动摇杆所在区域，用于控制角色移动。
  - **UI层级**：Unity层

- **底部中间区域 (社交区)**
  - **可用属性**：❌ **不可用 (系统保留)**
  - **核心功能**：包含文字聊天输入和语音社交。
  - **UI层级**：Unity层

- **右下区域 (动作与自定义操作区)**
  - **可用属性**：✅ **开放自定义 (创作者可用)**
  - **核心功能**：负责角色的移动、跳跃、手持交互等行为。
  - **业务场景**：开放自定义槽位，允许开发者在此区域自定义操作按钮（详见 [操作按钮](./系统交互按钮/操作按钮.md)）。
  - **UI层级**：Unity层

## 隐藏或禁用官方 UI

### 1. 隐藏系统界面层
根据业务需要，可分别隐藏 Native 层或 Unity 层的 UI：
- **隐藏所有原生层 UI (Native)**：
  ```csharp
  DouyinUIService.SetNativeUIVisible(bool visible);
  ```
- **隐藏所有系统 Unity 层 UI**：
  ```csharp
  DouyinUIService.SetUIVisible(bool visible);
  ```

### 2. 隐藏社交聊天面板
如果只需要单独隐藏聊天输入区域，可通过查找指定的 `GameObject` 来禁用：
```lua
local ui = UnityEngine.GameObject.Find("UISystem")
if ui ~= nil then
    local chat = ui.transform:Find("Canvas/UIRoot/Bottom/MainInputPanel(Clone)/ObserverNotHideLayer")
    if chat ~= nil then
        chat.gameObject:SetActive(false)
    end
end
```

### 3. 禁用或隐藏基础操作能力
可通过 `DouyinUIService.GetInteractionButton` 获取操作按钮引用并直接隐藏，或通过 `DouyinActor` / `DouyinPlayerSettings` 禁用底层能力：

- **飞行能力**：
  - 仅隐藏飞行按钮：`DouyinUIService.GetInteractionButton(HandType.Right, UIType.Fly).gameObject:SetActive(false)`
  - 禁用飞行并隐藏按钮：`DouyinActor.DisableFly(bool hideUI = true)`
- **牵手能力**：
  - 禁用牵手并隐藏按钮：`DouyinActor.DisableHoldHand(bool hideUI = true)`
- **合养精灵与角色功能**：
  - 禁用切换形象：`DouyinPlayerSettings.allowActorChange = false`
  - 禁用动作播放：`DouyinPlayerSettings.allowAction = false`
  - 禁用表情播放：`DouyinPlayerSettings.allowEmotion = false`
  - 禁用重生功能：`DouyinPlayerSettings.allowRespawn = false`

> **提示**：`UIType` 包含了 `CustomMain`, `CustomSub`, `Throw`, `Jump`, `MoveJoyStick`, `HoldHands`, `StopHoldHands`, `Fly`, `StandUp` 等，可根据需求定向隐藏。
