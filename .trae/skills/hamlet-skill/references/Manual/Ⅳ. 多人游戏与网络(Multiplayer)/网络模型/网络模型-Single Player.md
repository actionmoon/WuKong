# 网络模型 - Single Player

Single Player 模式适用于完全不需要多人网络同步，或仅有极少数弱联网请求（如只访问数据存储、排行榜）的单人体验。

## 特点

- **无网络同步开销**：场景中的物体无需挂载 `DouyinNetworkGuid`，可以直接使用 Unity 原生的 `Instantiate` 和 `Destroy` 进行动态创建与销毁。
- **本地逻辑**：所有逻辑、物理计算、碰撞检测均在本地客户端独立运行。
- **开发简单**：无需考虑主权（Ownership）、控制权（Controllership）、同步变量及 RPC 消息互通。

## 适用场景

- 单机解谜游戏、单人剧情体验。
- 个人空间、私密装扮房间。
- 纯展示类的交互空间。

## 注意事项

- 即使在 Single Player 模式下，也可以调用云端的**数据存储 (DataStore)** 或**排行榜 (Rank)** 等服务，以实现玩家个人的存档或全局排名。
- 如果后续需要将单机玩法扩展为多人联机，需重构所有动态对象的生成方式，并将需要共享的状态改为**同步变量**。
