# 断线重连机制

Douyin World 为应对移动端常见的网络波动，设计了完善的保活与断线重连机制。

## 1. 保活机制

### 房间保活
当所有用户主动退出房间或因网络断线等原因暂时离开后，房间不会立即销毁，而是进入保活状态并持续存活一定时间（单位：秒）。若保活期结束后仍无用户返回，系统将销毁房间。

### 用户保活
当用户发生**应用切后台**（锁屏、失去焦点）或**网络异常中断**（Wi-Fi弱、数据切换）时，系统会自动让该用户进入**保活状态**：
- 用户的主权会转移给房间内其他用户，但**控制权会保留**。
- 其他用户**不会**收到该用户离开的通知（不会触发 `OnPlayerLeft` 和 `OnActorDespawned`）。
- 若保活期结束仍未返回，系统将终止保活，清理内存并向其他用户广播 `OnPlayerLeft`。

## 2. 顶号机制

顶号机制针对多端登录或杀端重进：
- 跨设备顶号或同设备强制杀端后快速重登时，系统会将原房间内的旧连接强制踢下线。
- 新连接会重新进入房间，**历史信息不保留**，需要重新同步当前房间状态。

## 3. 核心流程与 API

在断线重连的生命周期中，会触发专属的系统事件，供开发者处理网络状态。

### 断线阶段
- 触发 `DouyinNetService.onDisconnect`。
- **注意**：断线时，由于处于保活状态，**不会**触发 `OnActorDespawned` 和 `OnPlayerLeft`。

### 重连恢复阶段
- 触发 `DouyinNetService.onReconnect`。
- 随后会重新触发 `OnActorSpawned` 和 `OnPlayerJoined`。
- **注意去重**：由于 `OnActorSpawned` 会被重复触发，若在其中编写了动态创建网络对象（`NetSpawn`）的逻辑，必须进行判空/去重处理，防止同一玩家在断线重连后生成多个相同的血条或特效对象。

```lua
function OnActorSpawned(actor)
    if not actor.isLocal then return end
    
    -- 【重要】防止断线重连时重复创建
    if hasSpawnedObject[actor.actorID] then return end
    
    actor:NetSpawn("MyNetworkObject", function(go, id)
        hasSpawnedObject[actor.actorID] = true
    end)
end
```
