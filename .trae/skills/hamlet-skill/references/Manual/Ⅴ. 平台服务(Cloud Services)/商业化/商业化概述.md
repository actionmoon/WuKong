# 商业化概述

商业化系统是抖音虚拟世界为创作者提供的内容变现解决方案。创作者可以通过配置虚拟商品，玩家使用星光币进行购买，从而为世界带来收益。

## 前置依赖

商业化方案的落地实施，需依托安全、稳定且可靠的运行环境。为确保系统环境满足商业化运行的基础要求，在正式接入商业化功能前，**必须完成 Dedicated Server (DS) 模式的接入**。严禁在客户端直接处理核心的订单发货与数据存储逻辑。

## 商品创建与管理

创作者可以在后台管理页面完成商品的注册与配置：

1. **商品创建**：进入世界详情页面，点击左侧【商业化】-【商品管理】，点击右侧【创建商品】。
2. **填写商品信息**：上传商品图标，输入商品名称、简介、定价等信息。保存后商品即完成创建（默认上架）。
3. **状态管理**：商品创建后，可以重新编辑、上架、下架或删除。商品状态变更后，可使用客户端 API 进行状态刷新。

## 交易核心流程架构

抖音虚拟世界采用了 **“客户端发起购买，服务端确认发货”** 的架构，以确保交易的安全性与幂等性：

1. **客户端发起购买**：客户端调用 `DouyinMarketingService.Purchase` 接口拉起支付面板，玩家确认并支付星光币。
2. **服务端接收回调**：支付成功后，平台向运行在 Dedicated Server 的服务端脚本发送 `onOrderPayment` 事件。
3. **服务端执行发货**：服务端监听到扣款成功事件，验证订单信息后，将对应商品及数量写入该玩家的 DataStore（原生 `DouyinDataStore`，以 `playerOpenID` 拼接为 `Scope` 隔离）。
4. **服务端同步状态**：发货数据落库成功后，服务端调用 `ConfirmOrder(code=0)` 通知平台发货成功。若落库失败则通知平台触发补单机制。

## 测试与调试

- **扫码调试**：世界构建完成后，在世界详情页【管理】-【版本管理】的开发版本记录中，点击右侧体验版本，使用抖音【扫一扫】扫描二维码即可进入测试环境。
- **测试商品**：测试购买流程需要真实扣除星光币，建议创建一个低价格的测试商品（如 1 星光币）。
- **过滤外显**：请注意测试商品的展示逻辑，通过商品 ID 列表（白名单机制）手动过滤测试商品，防止在正式环境中外露给普通玩家。
