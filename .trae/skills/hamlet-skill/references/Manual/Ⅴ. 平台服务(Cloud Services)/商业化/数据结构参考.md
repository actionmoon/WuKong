# 商业化数据结构参考

本文档详细列出了抖音虚拟世界商业化模块中常用的数据结构与枚举定义，供开发者在实现商品展示与订单处理时参考。

## 1. 商品状态枚举 (DouyinProductStatus)

标识商品当前在系统中的运营状态。

| 枚举值 | 取值 | 说明 |
| --- | --- | --- |
| Offline | 1 | 下架：已暂停销售的商品 |
| Online | 2 | 上架：当前可正常销售的商品 |
| Delete | 3 | 删除：已被逻辑删除的商品 |

## 2. 商品详细信息 (DouyinProductInfo)

调用 `GetProductInfos` 或 `GetProductInfo` 时返回的商品数据模型。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 商品唯一 ID |
| name | string | 商品名称 |
| desc | string | 商品描述 |
| iconUrl | string | 商品图标 URL |
| price | Int64 | 商品价格（星光币数量） |
| status | DouyinProductStatus | 商品状态 |
| extraData | string | 商品额外信息（开发者在后台配置的自定义信息） |

## 3. 商品分页数据模型 (DouyinProductPage)

用于在商品数量超过 50 个时，进行分页拉取的数据容器。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| pageOffset | int | 当前商品页的起始索引 |
| pageSize | int | 当前商品页的页面大小 |
| totalSize | Int64 | 当前所有商品的数量 |
| queryTime | Int64 | 查询时间的时间戳 |
| hasMore | bool | 是否还有更多的商品信息（用于判断是否继续拉取下一页） |
| productInfos | List\<DouyinProductInfo> | 当前页面的所有的商品信息列表 |

> 分页对象还提供“获取下一页”能力 `AdvanceToNextPage`：传入回调，回调返回错误码、错误信息与下一页的 `DouyinProductPage`。具体调用写法见 Best Practice。

## 4. 订单状态枚举 (DouyinOrderStatus)

标识一笔交易订单当前的流转状态。

| 枚举值 | 取值 | 说明 |
| --- | --- | --- |
| Init | 1 | 创建未付款 |
| Timeout | 2 | 支付超时 |
| Paid | 3 | 已支付待发货（此时应在 DS 服务端处理发货） |
| Shipped | 4 | 已经发货（DS 服务端已成功调用 ConfirmOrder） |
| Failed | 5 | 发货失败，已退款 |

## 5. 订单票据信息 (DouyinReceiptInfo)

在客户端购买完成 `onPurchaseResult` 和服务端扣款成功 `onOrderPayment` 事件中返回的核心凭证。包含验证交易合法性和发放具体物品所需的全部信息。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| orderStatus | DouyinOrderStatus | 交易订单的状态 |
| purchaseOrder | string | 交易订单号（全网唯一的流水号，常用于服务端实现发货幂等性） |
| playerOpenId | string | 交易用户的 OpenId |
| petOpenId | string | 精灵的 OpenId（如适用） |
| productId | string | 商品 ID |
| productNum | int | 商品交易数量 |
| productPrice | Int64 | 商品交易价格（单价） |
| orderPrice | Int64 | 订单的总价（单价 × 数量） |
| orderData | string | 订单的额外信息（客户端 Purchase 时透传的业务数据，原样回传） |
| purchaseTime | Int64 | 发货时间时间戳 |

## 6. 商品限购类型枚举 (DouyinProductLimitType)

（注意：此功能根据引擎版本开放程度可能处于测试中）

| 枚举值 | 取值 | 说明 |
| --- | --- | --- |
| None | 0 | 不限购：无任何购买数量限制 |
| All | 1 | 全局限购：累计购买数量达到上限后无法再买 |
| Daily | 2 | 每日限购：单日购买数量达到上限后无法再买，自然日 0 点重置 |

## 7. 商品限购数据 (DouyinProductLimit)

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| type | DouyinProductLimitType | 商品限购类型 |
| totalNum | Int64 | 商品限购次数（总配额） |
| availableNum | Int64 | 商品剩余购买次数（当前可用额度） |
