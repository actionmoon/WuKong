# 社交服务

`DouyinSocialService` 是一个全局静态类，封装平台向的**社交分享**与**投稿监听**能力：把「世界」或世界内画面分享给抖音好友 / 群组，并监听玩家将内容投稿为抖音视频的进度与结果。合理使用可提升世界的曝光与用户活跃度（社交裂变）。

本文档说明其能力概念、接口概览与硬约束边界。完整的可执行案例（分享封装、投稿监听生命周期、裂变奖励）见 Best Practice。

---

## 一、核心 API 概览

| API | 类型 | 作用 |
| --- | --- | --- |
| `ShareWorld(templateId, callback)` | 方法 | 将当前游戏世界分享给他人；`callback(bool)` 表示分享是否成功 |
| `ShareTexture(texture, callback)` | 方法 | 将指定图片分享给他人；`callback(bool)` 表示分享是否成功 |
| `onPublishProcessEvent` | 事件 | 监听玩家抖音视频投稿的**发布进度**（`publishId`, `process 0-100`） |
| `onPublishResultEvent` | 事件 | 监听玩家抖音视频投稿的**发布结果**（`publishId`, `success 1/0`, `contentId`） |

> **分享回调语义**：`ShareWorld` / `ShareTexture` 的 `callback(bool)` 只表示**分享操作是否成功唤起 / 完成**（`false` 含用户取消），**不代表**好友是否点击、是否成功进房。

---

## 二、两类能力

### 1. 世界分享（ShareWorld）

- 把当前世界作为一张 IM 卡片分享给好友 / 群组，好友点击可跳转进入世界。
- `templateId`：分享内容模板 ID，**必须预先在创作后台「社交分享能力」设置并通过审核**。
- 传空字符串 `""` 时，使用**官方默认世界分享模板**。
- **IM 卡自定义**：可在后台自定义卡片标题、描述、封面图；**标题最多 13 个字符**。

### 2. 图片分享（ShareTexture）

- 把世界内截图 / 实时渲染的图片分享给好友，被分享者可点击图片进入世界。
- 典型场景：结算战绩图（得分 / 排名）、装扮 / 建造作品「拍照」炫耀。
- **图片尺寸建议**：168 × 264（安卓）/ 168 × 224（iOS）；尺寸过小会导致预览显示不全。

### 3. 投稿监听（onPublishProcessEvent / onPublishResultEvent）

- 玩家把世界内容投稿为抖音视频时，可监听其**发布进度**（0-100）与**最终结果**（成功返回作品 `contentId`，失败无该参数）。
- `publishId` 形如 `hamlet_world_{时间戳}`，用于串联同一次投稿的进度与结果。
- 常用于投稿完成后给予奖励 / 提示。

---

## 三、社交裂变（结合房间来源）

- 世界分享可与**房间进入来源**配合做裂变奖励：被邀请者通过分享卡片进房时，房间信息中带有邀请人标识。
- 通过判断房间信息中的**邀请人 ID 是否为空**，识别当前玩家是否由分享卡片进入，从而对邀请者 / 被邀请者发放奖励。
- 详见 [房间服务](房间服务.md) 的 `enterFrom` 与 `inviterOpenID`。

---

## 四、硬约束与能力边界

- **仅线上环境可用**：社交分享能力**不支持本地调试器与扫码测试**，只能在线上环境验证；调用前应通过 `DouyinApplication.isSimulator` 拦截调试器环境。
- **模板需审核**：`ShareWorld` 的自定义 `templateId` 必须在创作后台配置并审核通过，否则应回退官方默认模板（`""`）。
- **IM 卡标题上限 13 字**：自定义分享卡标题最多 13 个字符。
- **回调不代表传播效果**：分享 `callback` 只表示是否成功发起，不代表好友点击 / 进房。
- **事件监听要清理**：`onPublishProcessEvent` / `onPublishResultEvent` 注册后需在销毁时移除监听，避免重复回调与泄漏。
