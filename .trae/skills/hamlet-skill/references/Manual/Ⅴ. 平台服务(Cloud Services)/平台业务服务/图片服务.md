# 图片服务

`DouyinImageService` 是一个全局静态类，提供**运行时从网络 URL 加载图片**的能力：把一个 HTTP(S) 图片链接下载并解码为 `Texture2D`，供 UI 或材质使用。

本文档说明其能力概念、核心 API、关键约束与能力边界。完整的可执行案例（下载封装、缓存、`Texture2D` 生命周期管理、赋值 UI、失败降级）见 Best Practice。

---

## 一、核心 API 概览

| API | 说明 | 是否异步 |
| --- | --- | --- |
| `DownloadImage(url, callback)` | 下载 `url` 指向的图片，解码为 `Texture2D` 后经 `callback` 回调返回 | 是（回调式） |

- **入参 `url`**：图片的下载链接（HTTP/HTTPS）。
- **回调 `callback`**：下载完成时触发，回调参数为下载得到的图片纹理（`Texture2D`）。下载成功回调返回可用的纹理；**失败时回调返回的纹理可能为空**，业务侧必须做空值校验。

> `DouyinImageService` 目前**只有 `DownloadImage` 一个方法**，没有取消下载、进度回调、批量下载或本地缓存接口。缓存、去重、生命周期管理都需要业务侧自行实现（见 Best Practice）。

---

## 二、典型 URL 来源

`DownloadImage` 本身不产生 URL，它总是与其他平台服务返回的图片链接配合使用。常见来源：

- **创作者头像**：`DouyinCreatorService.GetCreatorInfo` 返回的 `CreatorInfo.portrait`（见 [创作者服务](创作者服务.md)）。
- **官方奖励缩略图**：`DouyinOfficialRewardService.IssueReward` 回调中 `RewardInfo.imageUrl`（形象 / 装扮的缩略图，见 [奖励服务](奖励服务.md)）。
- 其他由业务后台或平台接口下发的图片 URL。

---

## 三、硬约束与能力边界

- **异步 + 判空**：`DownloadImage` 是异步回调，结果**不会立即返回**；回调中的 `Texture2D` 可能为空（URL 无效、网络失败、解码失败），赋值前必须判空。
- **URL 必须有效且可公网访问**：空串、非图片资源、需要鉴权或已过期的链接都会导致下载失败。URL 应来自平台接口返回，不要硬编码。
- **`Texture2D` 生命周期需自管**：下载得到的纹理是运行时创建的对象，**不使用时应调用 `UnityEngine.Object.Destroy` 主动释放**，否则频繁下载会累积显存占用。切勿在 `Update` / `FixedUpdate` 中反复下载同一张图。
- **无内置缓存与去重**：平台不缓存下载结果。相同 URL 的重复请求应由业务侧用字典缓存 `Texture2D`，并拦截并发的重复下载。
- **不保证回调时机与对象存活**：回调可能在若干帧后触发。回调执行时，目标 UI 组件（`RawImage` / `Image`）可能已被销毁，赋值前应校验目标对象仍然有效。
- **失败要降级**：下载失败时应展示占位图或保持原样，并给出必要提示，不要让 UI 停留在空白或报错状态。
