# 触发器生命周期与交互边界约束

## 1. 概念 (Concept)
触发器（Trigger）是判断玩家是否进入特定区域、能否触发交互面板的核心机制，主要通过 `OnActorTriggerEnter` 和 `OnActorTriggerExit` 来实现。

## 2. 边界 (Boundary)
- **职责边界**：触发器生命周期模块只负责阶段的 Enter/Exit 拦截、缓存当前玩家引用（如 `localActor`）以及挂接轻量级的交互开关（如 `EnableInteraction`/`DisableInteraction`）。

## 3. 规范 (Specification)
- **必需的本地玩家校验**：在进入和离开逻辑中，必须先做 `actor非空` 和 `actor.isLocal` 的过滤判断，否则远端玩家或其它 Actor 会错误地污染本地的交互状态。

## 4. 黄金法则与避坑指南 (Golden Rules & Pitfalls)
- **🚫 避坑：严禁越权处理核心业务**
  - 禁止将 `EnableInteraction()` 当作模块本体。它只是个平台 UI API，不是核心生命周期。
  - 禁止在 Exit 阶段直接切换与生命周期无关的主业务状态（如宣布任务完成）。Exit 只能用于清理当前上下文环境。
