# 相机服务与视觉反馈约束

## 1. 概念 (Concept)
官方相机服务 (`DouyinCameraService`) 用于制作追尾跟随、冲刺 FOV 变化等镜头效果，统一接管玩家的视角。

## 2. 边界 (Boundary)
- **合法入口**：必须使用 `CS.DouyinCameraService.GetCamera()` 等官方 API 访问相机，**严禁**直接使用 `Camera.main.transform` 进行强行控制。

## 3. 规范 (Specification)
- **参数控制边界**：`SetYaw` 等平滑回正逻辑应放在 `LateUpdate()` 中，以避免与平台默认的跟随逻辑产生时序冲突。FOV 的修改只影响视野范围，不能替代真实的摄像机物理位移。

## 4. 黄金法则与避坑指南 (Golden Rules & Pitfalls)
- **💡 黄金法则：空值兜底**
  调用 `GetCamera()`、`GetPitch()`、`GetYaw()` 时必须处理返回 `nil` (C# null) 的情况。官方服务在代理相机异常或未就绪时会返回空，业务代码不能直接默认其有值，否则会导致空引用报错。
