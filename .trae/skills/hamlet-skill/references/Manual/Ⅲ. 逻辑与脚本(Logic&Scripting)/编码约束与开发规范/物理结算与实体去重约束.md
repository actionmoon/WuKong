# 物理结算与实体去重约束

## 1. 概念 (Concept)
在实现游戏中的物理检测（如触发、碰撞、射线检测等）时，常常会产生得分、命中、收集或伤害等一次性结果。

## 2. 机制与规范 (Mechanism & Specification)
- **实体级归一化**：复杂模型通常由多个子碰撞体组成。结算去重的粒度必须是**玩法实体**，优先将 `collider` 归一化到 `attachedRigidbody.gameObject` 或根节点，然后进行结算判断。

## 3. 黄金法则与避坑指南 (Golden Rules & Pitfalls)
- **🚫 避坑：严禁用单个 Collider 做去重**
  严禁用 `reportedInside[collider]` 这种针对单个碰撞体做去重的方式。否则，当一个复杂实体进入时，由于其包含多个子碰撞体，会随机触发多次结算。
- **🚫 避坑：避免同步重开结算窗口**
  处理重置（Reset）时，下游回调不得在同一调用栈里把当前回合（Round）重新打开。`settled=false` 等开闸动作必须跨过当前物理帧（延迟到下一帧或短冷却后执行），防止同帧内的剩余碰撞体引发重复计分。
