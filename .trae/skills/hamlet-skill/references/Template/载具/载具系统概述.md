# 载具系统概述

平台的载具体系以 `UnityEngine.Rigidbody` + `velocity` 主动驱动为基础，在通用刚体范式上叠加**载具专属手感调校**（每帧刚体重设、10 步 FixedUpdate 顺序、mass·drag 抗推挤量级）和**介质差异**（地面 / 水面 / 悬浮 / 飞行）。本手册提供载具领域的入口 / 概念地图 / 章节导航。

---

## 一、载具在核心系统中的位置

载具是**玩家坐进 / 骑上去驾驶的物体**（车 / 船 / 悬浮滑板 / 飞行器 / 骑行生物），承担"玩家 → 载具 → 世界"的物理与交互桥梁。

- 底层物理：走 [Rigidbody-规则](../物理/Rigidbody-规则.md)（velocity 保留 y、MoveRotation、XLua `*`、Kinematic guard、W/S 双轴消费）
- 特殊场景：非载具的主动驱动物体（追踪 NPC / 遥控物）**不需要**载具专属调校
- 玩家上下车：交互链路走 [座位系统-规则](../../../Best%20Practice/基础交互/座位系统-规则.md)（`OnSeatEntered` / `OnSeatExited` / seat-alignment）

## 二、4 类介质决策树

| 介质 | 定义 | 典型对象 | 判断标准 |
| --- | --- | --- | --- |
| **地面** | 贴地行驶，靠重力接地 | 汽车 / 卡丁车 / 骑行生物 | 需要脚下有地面、会翻车、有重力接地 |
| **水面** | 贴水面行驶，y 分量由 y 阻尼收敛 | 船 / 快艇 / 冲浪板 | 长期停留在水面、有浮力、打湿感 |
| **悬浮** | 离地固定高度飘行，y 由脚本 Raycast + PD 控制 | 悬浮滑板 / 气垫船 | 离地固定高度、不落地、不飞高 |
| **飞行** | 完全脱离重力自由三轴 | 飞碟 / 直升机 / 战斗机 | 完全脱离重力、玩家能控制 Y 升降 |

**特例**：飞行生物骑行（龙 / 飞鹰 / 翼兽）仍归"地面骑行生物"子模板，通过 `controlProfile = "flying"` + `allowVerticalControl = true` 实现空中飞行，与飞行介质（飞碟 / 直升机）的骨架**互斥不叠加**。
