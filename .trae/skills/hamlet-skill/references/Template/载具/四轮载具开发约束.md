# 四轮载具与物理驱动模板约束

## 1. 概念 (Concept)
在开发四轮汽车、卡车等物理载具时，载具的运动由物理引擎驱动，而视觉表现由动画驱动。

## 2. 边界 (Boundary)
- **物理与视觉解耦**：载具的真实移动必须由 `Rigidbody.velocity` 和 `MoveRotation` 驱动。轮子的旋转只是基于速度的纯视觉动画表现。两者不可混为一谈。

## 3. 规范 (Specification)
- **单一文件约束**：复杂的四轮地面载具应采用一体化的 Root-bound 脚本（如 `pi-vehicle.lua`），严禁将其拆分为单独的驱动、轮子动画或座位脚本，避免时序不同步。

## 4. 黄金法则与避坑指南 (Golden Rules & Pitfalls)
- **🚫 避坑：参数暴露克制**
  向玩家暴露的参数必须克制。仅暴露核心调优参数（如最高速、加速度、抓地力）与 UI 文本。**严禁**将内部的稳定状态保护参数（如防翻滚辅助角、紧急制动阈值、模型轮子半径）暴露到面板上，以免被误改破坏物理表现。
