# 创作者手册 (Creator Documentation)

欢迎来到抖音虚拟世界 UGC SDK 创作者文档中心。为了帮助开发者更高效地检索信息并建立清晰的心智模型，我们将整个文档体系严格划分为三个核心层级：**使用手册 (Manual)**、**API 参考 (API Reference)** 与 **最佳实践 (Best Practice)**。

---

## 1. 使用手册 (Manual)

`Manual` 是产品与工具的**完整使用指南**。它的核心原则是将庞杂的引擎功能，转化为符合新手学习和游戏开发生命周期的模型。
本部分**仅包含基础示例**，旨在帮助开发者快速理解概念并跑通主流程。

### 1.1 核心架构层级 (Architecture Hierarchy)
手册的目录结构映射了游戏引擎的底层架构设计，自下而上分为五大核心支柱：
- **核心系统 (Core)**：虚拟世界的基石。涵盖对象生命周期、角色控制、输入机制等。
- **界面与交互 (UI)**：人机交互的桥梁。负责呈现游戏状态并接收玩家交互。
- **逻辑与脚本 (Logic & Scripting)**：提供渐进式的编程范式（ECA、Lua、C#）。
- **多人游戏与网络 (Multiplayer)**：处理状态同步、RPC 通信与网络对象生命周期。
- **平台服务 (Cloud Services)**：提供云端数据库、商业化发货等运营后盾。

### 1.2 开发者学习路径 (Developer Learning Path)
- **阶段一：单机原型构建** (`核心系统` -> `界面与交互` -> `ECA`)
- **阶段二：深度定制** (`脚本开发` -> `核心进阶` -> `交互进阶`)
- **阶段三：网络与运营** (`网络架构` -> `平台服务` -> `商业化`)

### 1.3 编码红线与开发规范
在学习 Manual 时，请特别关注全局抽离的底层限制与易错点，详见 [编码约束与开发规范](Manual/Ⅲ.%20逻辑与脚本%28Logic%26Scripting%29/编码约束与开发规范.md)。

## 2. API 参考 (API Reference)

`API Reference` 是引擎接口的**查阅字典**。

为了方便开发者快速检索和总览所有的核心类与服务，我们提供了一份按核心架构层级分类的 [**API 参考目录索引 (API Reference Index)**](API%20Reference%20Index.md)。

### 2.1 API 权限管控 (API Access Control)
为了保证运行环境安全与脚本沙箱权限约束，引擎对 Lua 侧的 API 调用进行了严格限制：
- [**API 白名单 (API Whitelist)**](API白名单.md)：规范 Lua 脚本内允许访问、调用的 Unity 官方引擎命名空间及项目专属组件。
- [**API 黑名单 (API Blacklist)**](API黑名单.md)：说明 Lua 脚本中不可直接访问或调用（包括通过反射）的 API、基础类型和标准库能力范围。

### 2.2 枚举参考 (Enum Reference)
- [**系统枚举目录 (Enum)**](Enum/)：汇总了引擎中常用的各类枚举定义，例如角色状态、交互类型、订单状态等，方便在编写脚本时查阅具体的枚举项及数值。

### 2.3 接口详尽说明
当你在 `Manual` 或 `Best Practice` 中了解到某个类或方法，并需要知道它的精确用法时，请查阅 API 参考目录。
这里包含了具体 API 的详尽技术说明，包括但不限于：
- **Class (类)** 的继承关系与定位。
- **Property (属性)** 的类型、读写权限与默认值。
- **Method / Function (方法/函数)** 的参数列表、返回值与异常抛出。
- **Event (事件)** 的触发时机与回调签名。

## 3. 最佳实践 (Best Practice)

`Best Practice` 是**进阶示例**与**经验沉淀的推荐做法**。

当开发者已经掌握了 `Manual` 中的基础概念，但在实现复杂业务（如飞行载具、状态机、多端同步策略）时遇到瓶颈，或者需要查阅 C# 与 Lua 的对比实现方案时，应参考此目录。
