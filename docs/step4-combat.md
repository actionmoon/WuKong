# 步骤 4：玩家基础战斗

战斗数值、动作事件、根运动和胶囊参数由参考资源生成；DS 决定动作是否合法、体力与棍势消耗、命中、无敌和治疗。客户端发送输入与递增命令编号，并播放同步姿态、更新 HUD。每位玩家拥有独立挑战数值，其他客户端可观察其结果。

## 本地回归

1. 在 Unity 打开 `Assets/WuKong/Scenes/WuKongTiger.unity`，刷新并保存场景，执行 `Tools/ScenePackage`，确认构建完成。
2. 执行 `python3 -B tools/run_sample.py --dry-run`，随后执行 `python3 -B tools/run_sample.py --hold`，启动 DS 与两个客户端。
3. 聚焦客户端按 F8，DS 输出 10 项固定用例结果。按 F7 运行约 34 秒的客户端输入回放，依次执行五段连招、一级蓄力、受击与治疗、完美闪避、移动和疾跑轻棍。
4. 按 F9 重置当前玩家的挑战数值并到达练习点；按 F10 安排 0.7 秒后的测试来袭。来袭仅在玩家距目标 5 米内生效。
5. 用鼠标或触摸按钮完成手动操作。在另一客户端日志中核对相同 actor 的 `play`、`hits`、`bossHp`、`hp`、`heals` 和 `perfect`。
6. 执行 `python3 -B tools/record_combat_evidence.py <本轮会话目录>`，将结果保存到 `docs/reference/step4-runtime-evidence.json`。结束启动器并确认本轮三个进程退出。

F7—F10 的输入入口及测试来袭只在 `isSimulator` 环境开放。F8 使用隔离的 DS 状态机上下文；F7 使用真实客户端、网络请求、场景骨骼和同步变量。二者分别验证数值规则和实际端到端行为。
