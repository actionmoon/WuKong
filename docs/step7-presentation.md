# 界面、音效、特效与性能

本步沿用 [任务计划](plan.md) 的步骤 7，开发与验证规则沿用计划中的单一事实来源。

1. 界面使用 Overlay Canvas 和横屏固定高度缩放，按屏幕安全区调整容器。缓存文字、按钮和资源条引用，文字以 10 Hz 刷新并仅在变化时写入；血条显示即时缓动及延后下降的伤害余量。界面包含血量、法力、体力、四段棍势、葫芦、变身与精魄能量、法术冷却、锁定、帮助和延迟出现的胜败 / 重试面板。
2. 按源配置偏移拆出 619 个 Opus 片段，转换为 Unity 可导入音频，并沿用 293 个事件的增益、随机变体与距离衰减。四段 BGM 使用流式加载；音效使用压缩内存加载和 40 个复用声源。304 个动画合同共提取 2,074 个声音通知，覆盖脚步、装备动作、攻击和技能，播放时间由战斗快照决定。M 或声音按钮切换静音；重试停止已有声音与音乐。
3. 转换 39 张源纹理，建立 80 项表现映射、武器拖尾模板和最多 64 个特效实例，每类最多三个实例，每个发射器最多 128 个粒子。动作通知驱动粒子与拖尾，命中、定身、化气、石化、变身和毒蛇状态驱动补充表现。石化使用源岩石纹理与 20 倍平铺；聚形散气保留淡化的人形。镜头通过平台相机服务跟随立棍抬高的骨盆，并按广智源配置增加距离和高度。
4. 运行时采样实际帧时间、Unity 分配内存和输入 / 快照 JSON 字节数；每十秒缓存场景 Renderer 与网格索引数，每五秒统计当前可见 Renderer 和网格三角形数量。后者是可见网格实例估计，不是 GPU draw call 或完整提交三角形数，粒子、拖尾和新增实例可能不在该区间缓存内。F4 在调试器中检查四种横屏分辨率的按钮边界和相互重叠；F5 / F6 沿用技能和 Boss 回放。所有这些诊断入口仅在调试器生效。

资源与实现：

- [资源转换器](../tools/prepare_presentation.py)、[转换证据](reference/step7-asset-evidence.json)：包含声音片段偏移、原始字节 SHA-256 和解码后时长。
- `Editor/WuKongPresentationBuilder.cs` 导入音频 / 纹理并装配界面、粒子模板与 Lua 资源引用。
- `Client/PresentationHUD.lua`、`PresentationAudio.lua`、`PresentationFX.lua` 分别维护界面、声音和特效；`PresentationMetrics.lua` 记录调试器性能。
- 资源条与文字移至左上，帮助 / 声音移出右上 Native 功能区；定向隐藏平台跳跃、飞行、投掷及聊天面板，保留官方摇杆。重试恢复出生 yaw、pitch、高度和距离。角色动画每帧只采样一次，Boss 缓存镜头脚本和危险物材质引用。
- [运行取证脚本](../tools/record_presentation_evidence.py) 从 DS 与两端实际日志提取固定用例、快照、声音状态、特效计数和性能样本。

首轮运行的触摸区域类型错误已定位并修正：鼠标坐标需从 Vector3 显式转换为 Vector2，并传入相机参数。失败结果保留在 [首轮证据](reference/step7-first-attempt.json)；失败轮没有完成战斗验证。

已取得的实际基线：

1. 会话 `hamlet-simulator-l8iiag5e` 完成 DS、两客户端技能回放，服务端固定用例 59/59，三端 Lua 异常为 0。声音实际播放 135 次，含 14 次脚步、41 次装备声音，采样声源峰值 6；特效爆发 35 次，采样粒子峰值 65。两端共享快照以及重试清理见 [基线证据](reference/step7-baseline-evidence.json)。
2. 真实键盘 M 切换静音通过。BGM 观察到一级开场、一级循环和结束段。F4 在 960×540、1280×720、1600×720、1024×768 四种实际窗口尺寸检查，战斗按钮越界 0、相互重叠 0。
3. Apple M5 Pro、48 GiB 内存、18 CPU 核的 macOS 调试器中，客户端 A 战斗样本均值 56.74 FPS，包含加载阶段的最低区间 48.76 FPS；五秒采样的帧时间 P95 最大约 17.59 ms。Unity 已分配内存峰值约 1.35 GiB。JSON 业务载荷均值约输入 2.8 KiB/s、共享快照 25.0 KiB/s。两窗口同时运行，其中客户端 B 为 3456×1978 窗口；不能据此推断手机性能。
4. macOS 窗口截图确认帮助 / 声音与血条等文字可见。资源文字和血条已移出左下摇杆区，帮助 / 声音已移出右上系统区；挑战按钮层级和重试镜头恢复已修正。部分 SDK 交互标记仍可见，四种分辨率的按钮检查只涵盖本项目战斗按钮，不代表系统叠层全部消失。
5. 渲染采样首次缓存已销毁的变身 Renderer 后报错，已按 SDK 的 `IsNull()` 规范修正；[失败轮](reference/step7-render-cache-attempt.json) 保留原始异常与回放结果。后续回归见最终记录。

最终回归：

1. 会话 `hamlet-simulator-n6ore4o8` 的运行固定用例 77/77（原 59 项加 Boss 18 项重跑）、三端 Lua 异常 0；技能回放完成，Boss 回放覆盖石化、隐身、二级音乐、胜败与重试。最后一段重棍致死未完成，结束 Boss HP 1，本项未判通过。完整快照与事件见 [最终运行证据](reference/step7-runtime-evidence.json)。
2. 四种横屏项目按钮边界再次检查通过。技能窗口与 Boss 表现截图已保存；真实键盘与第二端路线取证见计划 5.8。声音累计播放 315 次、声源峰值 6；特效爆发 110 次、粒子峰值 304。仍有 13 次声音事件与 2 次特效映射未找到，不能声称源通知全部覆盖。
3. 两个 1200×676 macOS 窗口同时运行，战斗样本均值 57.27 FPS，最低五秒区间 48.71 FPS，P95 最大 17.60 ms，Unity 分配内存峰值约 1.35 GiB。A 可见 Renderer 385～1789、缓存网格三角形约 115～413 万。输入 JSON 均值 2.70 KiB/s，共享快照 24.83 KiB/s。上述数据来自实际调试器，未设手机性能通过阈值。
4. 三端已确认退出，自动技能 / Boss 回放标记已清除。交付场景于 `2026-11-22 15:15:45 +08:00` 保存，最终 Addressables 缓存于 `15:16:03 +08:00` 更新；本地启动前提校验与 31 个 Lua 文件语法检查通过。见 [最终构建证据](reference/step7-delivery-build.json)。核心实现与本轮回归完成，等待人工确认进入步骤 8。

还原差异与验收边界：

- Niagara 的网格、折射、屏幕后处理和部分源曲线使用 Unity 精灵粒子近似。75 项源系统中 61 项可提取到直接粒子映射；拖尾采用挂点轨迹，未实现原网页跨整根武器的多层折射带。
- 死亡表现采用透明淡出，未实现原材质的噪声溶解。石化当前依据战斗状态切换岩石层，未逐项还原毛发及手臂材质曲线。
- 命中声音在快照血量变化时播放，缺少精确命中音频 ID 时沿用原网页的默认 ID。一次快照间隔内的多次命中可能合并为一次表现。
- macOS 调试器的帧率、内存和按钮布局不代表目标手机验收。触摸真机、多指长按与听感验收需独立取证。
- 桌面键盘 H / M / F4 / F6 与第二端 T 已实际操作。Computer Use 点击图中按钮时，Unity 收到的坐标与目标矩形不一致，鼠标按钮点击未判定通过；未将程序调用按钮监听当成实际点击证据。
- 流量采样只统计 UTF-8 JSON 业务载荷，不包含 SDK 包头、Actor 同步及传输重试。
- 已有 glTF ShaderGraph BuiltIn Deferred / Metal 编译问题沿用此前记录，场景使用转换后的 `World_Lit` 材质；本步不把构建缓存更新等同于该问题解决。
